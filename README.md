# Hunter 6.0 — Autonomous Options Trading with Delta Hedging

Полностью автономная мультиагентная система для торговли опционами на Bybit с динамическим хеджированием дельты. Обнаруживает аномалии в улыбке волатильности, автоматически выставляет Long Strangle и хеджирует дельту фьючерсами. Самообучается на потоковых данных через адаптивные пороги Isolation Forest.

## ✨ Ключевые возможности

- **Адаптивный детектор аномалий** — Isolation Forest с онлайн-обновлением порогов
- **Автоматический Position Builder** — комбинированные ордера (Long Strangle)
- **Динамическое хеджирование дельты** — подписка на WebSocket позиций, автоматическая ребалансировка
- **Промышленная надёжность** — Kafka (A2A-шина), Prometheus + Grafana, отказоустойчивость
- **Полная автономность** — запуск одной командой, без ручного вмешательства

## 🧠 Архитектура

- **A2A-шина**: Apache Kafka
- **Исполнение**: Bybit V5 API (опционы и фьючерсы)
- **Мониторинг**: Prometheus + Grafana
- **Самообучение**: адаптивные пороги детектора
